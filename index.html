Proyectos Destacados

Proyecto Destacado Full-Stack
Marketplace Web • E-commerce B2B/B2C

ALIMOP – Plataforma Marketplace de Alimentos

Solución web integral diseñada para conectar proveedores de alimentos (productores agrícolas, panaderías, carnicerías y restaurantes) con clientes finales. El sistema incorpora clasificación técnica de inocuidad alimentaria, gestión de inventario en tiempo real, carrito de compras persistente y despacho de órdenes.

Aportes Técnicos Principales:

  • Desarrollo de API REST con Node.js y Express (11+ endpoints con autenticación JWT).
  • Base de datos en PostgreSQL con connection pooling parametrizado para seguridad estricta.
  • Carga multimedia en la nube conectando Multer con ImageKit CDN.
  • Frontend dinámico en React 18, Vite y Bootstrap 5 con panel administrativo.
  • Pruebas unitarias y de integración implementadas con Jest y Supertest.
React 18 Vite Node.js Express PostgreSQL JWT ImageKit CDN Jest

App Móvil Android Nativa
Android • Firebase • Arquitectura por Eventos

GymSync – Aplicación Móvil de Gestión de Gimnasios

Aplicación móvil nativa en Kotlin diseñada bajo el patrón arquitectónico MVVM para conectar a clientes de gimnasios con la administración. Incorpora sincronización en tiempo real, orquestación de eventos asíncrona, control de asistencias y soporte para Android 15+.

Aportes Técnicos Principales:

  • Arquitectura reactiva con Kotlin, MVVM, LiveData y SharedFlow.
  • Integración con Cloud Firestore (listeners en tiempo real) y Firebase Auth con verificación de correo obligatoria.
  • Pipeline de eventos asíncrono conectando Retrofit 2, n8n (Docker) y Make.com para reservas y notificaciones por Gmail.
  • Módulo de Administrador con gestión de clases (CRUD con soft-delete y cancelación en cascada) y asistencias atómicas con WriteBatch.
  • Soporte Edge-to-Edge con Window Insets y notificaciones locales de alta prioridad (Android 13+ POST_NOTIFICATIONS).
Kotlin Android SDK MVVM Cloud Firestore Firebase Auth Retrofit 2 n8n (Docker) Make.com
